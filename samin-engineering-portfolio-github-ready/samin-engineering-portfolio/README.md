# Samin Hussain — Engineering Portfolio

A responsive static portfolio built with HTML and CSS for GitHub Pages.

## Pages
- `index.html` — homepage
- `about.html` — personal/engineering story
- `projects.html` — project showcase
- `experience.html` — leadership and experience
- `contact.html` — contact links

## Before publishing
1. Replace the placeholder email in `contact.html`.
2. Replace the GitHub and LinkedIn URLs.
3. Replace the homepage photo placeholder with a real image when ready.
4. Add project photos to `assets/` and swap them into the project visual areas.
5. Commit the files to GitHub and enable GitHub Pages from the repository settings.

The site intentionally uses CSS-generated visuals so it does not depend on the old CodeHS/stock-image URLs.
